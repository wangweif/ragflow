1. 整体架构思路
一个系统，只有一个租户，租户下面可以配置团队，团队下维护成员
知识库挂在管理员名下，管理员可以创建知识库，管理知识库权限。普通用户可以上传文件共用
2. 任务梳理
  [] 管理员维护团队
  [] 管理员维护团队成员
  [] 管理员维护知识库权限
  [] ai助手选择知识库权限控制
3. 接口梳理
  1. 创建团队
  2. 团队编辑
  3. 创建团队成员
  4. 团队成员编辑
  5. 知识库权限维护
  6. ai助手知识库权限选择
4. 关键业务实现逻辑
  1. 创建团队
    1. 创建一张新表
    2. 关键字段 租户id, 团队名称
    3. 团队名称验证是否重复，同一租户下
  2. 知识库权限维护
    1. 创建一张知识库和用户的关系表
    2. 关键字段 租户id, 团队id, 用户id，知识库id
  3. ai助手知识库选择
    1. 查询关联的知识库用户权限关系表，找到和该用户相关的知识库
